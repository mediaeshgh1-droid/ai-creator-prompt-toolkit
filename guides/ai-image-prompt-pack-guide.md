# AI Image Prompt Pack Guide
## ChatGPT / Gemini / Google Flow

A practical guide for creating high-quality AI images using a reference photo and a professional prompt workflow.

---

# General Rules for All Three Tools

Before generating an image, follow these rules:

1. Always write the prompt in **English**.
2. Upload your **reference image** before using the prompt.
3. Clearly state the required **aspect ratio**.
4. Keep the reference image as the main source of truth for identity.
5. If the result needs improvement, refine it conversationally instead of rewriting the entire prompt.
6. When identity preservation is important, explicitly state that the face, eyes, hair, skin tone, and recognizable facial features must remain faithful to the reference.
7. Avoid unnecessary changes to the person's appearance, clothing, or proportions.
8. When editing an existing generated image, ask the model to modify only the requested elements and keep everything else unchanged.

---

# 1. ChatGPT

ChatGPT can be used to create and edit images directly inside a conversation.

## Basic Workflow

1. Open ChatGPT.
2. Start a new conversation.
3. Upload your reference image.
4. Paste one of the English prompts below.
5. Generate the image.
6. If something needs to be changed, continue in the same conversation and describe the change naturally.

For example:

> Keep everything exactly the same, but change the background to a darker warm brown.

There is no need to rewrite the entire prompt.

## Best Practices

For identity-sensitive images, use instructions such as:

- Use the uploaded reference image as the only source of truth for identity.
- Preserve the exact facial structure.
- Preserve the person's natural skin tone.
- Preserve the hairstyle and hair color.
- Do not beautify or redesign the face.
- Keep realistic skin texture and natural pores.
- Do not change recognizable facial features.

---

# 2. Gemini

Gemini can also be used for image generation and image editing with reference images.

## Basic Workflow

1. Open Gemini.
2. Start a new conversation.
3. Upload your reference image.
4. Select the image creation option.
5. Paste the English prompt.
6. Generate the image.
7. If available, use the higher-quality generation option such as **Pro** for more demanding results.
8. Use conversational editing to refine the result.

## Identity Preservation

When working with a person's photo, explicitly tell Gemini to preserve:

- Facial identity
- Eye color
- Hair color
- Hair texture
- Facial proportions
- Skin tone
- Recognizable features

Do not rely only on phrases such as "make it look like the reference."

Be explicit.

---

# 3. Google Flow

Google Flow is useful when you want to build cinematic image and video workflows.

## Basic Workflow

1. Open Google Flow.
2. Upload the required reference image.
3. Add your prompt.
4. Use the available image-generation tools.
5. Use **Ingredients** when you need to maintain specific visual elements.
6. Use **Camera Controls** when creating cinematic compositions.
7. For video workflows, use the generated image as a keyframe/reference.
8. Refine the result through additional prompts.

## When to Use Google Flow

Google Flow is especially useful when you want:

- Cinematic compositions
- Consistent visual elements
- Image-to-video workflows
- Camera movement
- Product advertising
- Character consistency
- Professional commercial scenes

# Recommended Workflow

For the best results, use the following workflow:

## Step 1 — Upload the Reference

Upload the original image that contains the person or product you want to preserve.

## Step 2 — Paste the Prompt

Copy one of the prompts from this guide and paste it directly into the image-generation tool.

## Step 3 — Generate the First Version

Do not immediately rewrite the prompt if the first result is not perfect.

Instead, continue the conversation.

For example:

> Keep the face exactly the same, but make the lighting warmer.

Or:

> Keep everything unchanged except the dress. Change it to a black satin dress.

## Step 4 — Make Targeted Corrections

Use short, specific corrections.

Examples:

> Keep the same face and hairstyle. Make the cake slightly smaller.

> Keep everything identical. Remove the extra balloon in the background.

> Do not change the person. Only change the background to a dark warm studio.

## Step 5 — Lock the Final Image

Once the result is correct, avoid unnecessary additional changes.

# Prompt Engineering Principles

## 1. Reference Image First

When identity matters, the reference image should be treated as the primary source of truth.

## 2. Describe the Scene

Specify:

- Subject
- Clothing
- Pose
- Props
- Background
- Lighting
- Camera
- Lens
- Composition
- Mood
- Aspect ratio

## 3. Control What Must Not Change

Negative constraints are especially useful when the model tends to redesign the subject.

Examples:

> Do not change the face.

> Do not alter the hairstyle.

> Do not add extra fingers.

> Do not redesign the clothing.

> Do not change the product shape.

> Do not add unnecessary objects.

## 4. Refine Instead of Rewriting

If an image is already close to the desired result, use conversational editing.

This helps preserve the successful parts of the previous generation.

---

# Example Refinement Prompts

### Change Only the Background

> Keep the person, face, hair, clothing, pose, lighting, and composition exactly the same. Change only the background to a dark luxury studio environment.

### Change Only the Outfit

> Keep the person's identity, face, hair, pose, lighting, and background exactly unchanged. Replace only the outfit with a fitted black satin dress.

### Improve Realism

> Keep the composition and identity exactly the same. Increase realistic skin texture, natural pores, subtle imperfections, and authentic photographic detail. Avoid plastic skin or excessive retouching.

### Remove an Object

> Keep everything exactly the same except the specified object. Remove the extra balloon from the background and reconstruct the surrounding area naturally.

### Change Aspect Ratio

> Keep the image composition and all visual elements unchanged. Reframe the image naturally for a vertical 9:16 composition.

# Conclusion

The most important principle when using reference-based AI image generation is simple:

**Do not let the model reinterpret what you want to preserve.**

Clearly define the reference image as the source of truth, describe the desired scene precisely, and make targeted conversational corrections instead of repeatedly rewriting the entire prompt.

This workflow can be used across:

- Birthday portraits
- Fashion photography
- Product advertising
- Social media content
- Personal branding
- Editorial photography
- Product photography
- AI-generated campaigns
- Image-to-video workflows

The same principles can be adapted to ChatGPT, Gemini, Google Flow, and other modern AI image-generation tools.
