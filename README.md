# 🚀 Quick Start

You don't need to understand prompt engineering to start.

### 1. Choose a prompt

Browse the [`prompts/`](./prompts/) directory and find a prompt that matches your goal.

### 2. Replace the variables

Some prompts contain placeholders such as:

```text
[PRODUCT_DESCRIPTION]
[BACKGROUND_COLOR]
````

Replace them with your own information.

### 3. Upload your reference image

If the prompt is reference-based, upload the image you want the AI to use as the visual source of truth.

### 4. Paste the prompt

Copy the prompt into your preferred AI image or video generation tool.

### 5. Refine the result

Instead of rewriting the entire prompt, make targeted changes.

For example:

```text
Keep everything the same, but change the background to a dark green studio.
```

or:

```text
Keep the person and clothing unchanged. Make the lighting warmer and more cinematic.
```

# 🎯 Design Philosophy

This project follows a few simple principles.

### Reference First

When a reference image is provided, it should be treated as the primary visual source of truth.

Important elements should not be randomly redesigned.

### Practical Over Theoretical

Prompts should be useful in real content-production workflows.

The goal is not to create complicated prompts just to make them look impressive.

### Reusable

Prompts should be easy to adapt for different:

* Products
* People
* Brands
* Campaigns
* Visual styles
* Social platforms

### Conversational Refinement

AI image generation works best as an iterative process.

Generate → inspect → refine → generate again.

# 💡 Adding a New Prompt

A simple prompt file can follow this structure:

```markdown
# Prompt Name

## Description

Briefly explain what the prompt is designed to create.

## Prompt

Your prompt goes here.

## Variables

- `[VARIABLE_1]` — Description
- `[VARIABLE_2]` — Description

## Recommended Format

9:16
```

This keeps prompts consistent and easy to reuse.
